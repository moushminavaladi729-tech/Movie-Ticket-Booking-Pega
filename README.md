# Movie Ticket Booking Management Application

A Movie Ticket Booking Management Application designed using Pega Blueprint as part of the Pega National Internship Program.

## Project Overview
The application manages the movie ticket booking process from request submission to booking confirmation.

## Key Features
- Submit movie ticket requests
- Check show and seat availability
- Calculate total booking cost
- Confirm or cancel booking requests
- Maintain movie and show information
- Review booking details
- Process ticket booking
- Generate booking confirmation
- Define booking SLA
- Route bookings based on show type

## Case Type
Movie Ticket Request

## Technologies Used
- Pega Platform
- Pega Blueprint

## Project Workflow
Ticket Request → Availability Check → Cost Calculation → Customer Confirmation → Booking Execution → Notification
